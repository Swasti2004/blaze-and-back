# Agent instructions

Read `docs/PROJECT_BRIEF.md` first, then `.github/copilot-instructions.md`, then the task you were
given in `docs/COPILOT_TASKS.md`.

Short version:
- Run `python -m pytest -q` before finishing; add tests for every change.
- One task per commit, small diffs, no new dependencies without a reason.
- Never break the privacy, safety and untrusted-text rules in section 5 of the brief.
- Never edit the author's evidence in `docs/BUILD_LOG.md` or invent results of any kind.
- Say what you changed, and what you did not verify.
